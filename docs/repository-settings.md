# Repository Settings

Use this file after creating a real repository from the template.

## GitHub About

Suggested fields:

- Description: Bridge Superwhisper clipboard dictation into the Pi TUI editor on Windows.
- Website: npm package URL or project docs URL
- Topics:
  - `pi`
  - `pi-package`
  - `pi-extension`
  - `superwhisper`
  - `clipboard`
  - `windows`
  - `typescript`

## Template mode

This repository is a concrete package, not a template. Do not enable template mode unless it is intentionally turned into a reusable starter.

## Branch protection

Recommended for public packages:

- Require pull request before merging
- Require status checks to pass
- Require `CI` workflow
- Block force pushes on the default branch

## npm package page

After first publish:

- Confirm README renders correctly
- Confirm package provenance appears
- Confirm package contents are intentional
- Add npm URL to GitHub About and README
